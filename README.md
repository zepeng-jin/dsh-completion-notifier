# dsh-completion-notifier

[English Documentation](README.en.md) | 中文说明

DeepSeek Harness (DSH) 任务完成通知、审批提醒与会话命名插件。

在长任务跑完或 AI 等待你点击「允许」/ 审核 Plan 时，通过 macOS 系统通知横幅、DSH 应用内浮窗和提示音提醒你；支持全量提醒或仅在后台切走时提醒；可开启自动切换会话；首轮对话结束后自动给会话起个正常的名字，不再满屏都是 `task ready`。

---

## 为什么做这个插件？

平时用 DSH 让 AI 跑复杂任务，动辄几分钟，我们通常会把窗口最小化去干别的事。但经常会遇到这几个尴尬场景：

1. **不知道任务什么时候跑完**：要么每隔一会儿切回来瞄一眼，要么忘了切回来，白白浪费时间。
2. **在 DSH 窗口内反而收不到提醒**：macOS 系统通知中心默认会对前台活动应用静默抑制横幅，如果你正在看设置或别的窗口，系统横幅根本不飘出来。
3. **AI 卡在半路干等**：有时候 AI 刚跑两步就停下来等我们点击「允许」授权，或者在 Plan 模式下等我们「批准方案」。因为没发通知，窗口在后台一停就是半小时。
4. **多任务跑完找不到会话**：后台会话完成后，还得自己去左侧侧边栏茫茫多的列表里一个个翻找刚才跑的是哪个。
5. **侧边栏名字毫无意义**：DSH 默认经常把会话命名成 `task ready`、`task ready (1)` 或一行很长的路径/命令行，会话一多根本分不清。

这个插件就是为了彻底解决这些日常使用中的烦恼。

## 主要功能

- **任务完成提醒**：对话或任务跑完后，弹出系统通知横幅并播放提示音。横幅带 DSH 鲸鱼图标，附带耗时统计和 AI 回复的摘要。
- **DSH 应用内浮窗通知 (前台 100% 可见)**：专门解决 macOS 在前台使用时屏蔽系统横幅的问题。在 DSH 窗口右上角滑出轻量浮窗，无论何时都不漏通知。
- **自由选择提醒时机**：
  - **全量提醒（推荐）**：无论你当前是否在使用 DSH，都发出声音与通知；
  - **仅在未聚焦 / 后台时提醒**：当前正在看着 DSH 窗口时静默，只有窗口最小化或切到其他软件时才提醒。
- **自动跳转到对应会话**：开启后，后台任务完成或停下来等待审批时，无需手动点击，DSH 自动切入该会话。
- **等待操作提醒**：当 AI 停下来等待你点击「允许」（权限审批）、审核 Plan 计划或回答选择题时，会发出提醒，避免 AI 在后台干等。
- **点击横幅直达会话**：点击系统通知横幅或应用内浮窗，窗口自动激活并直接切换到对应的会话。
- **会话自动命名**：第一轮对话完成后，根据你的实际提问自动提炼 6~10 个字的简明中文标题，替换掉默认的 `task ready`。
- **防打扰阈值**：可以设置最短耗时（默认 3 秒），日常简单问答不弹通知，只在真正耗时的长任务跑完时才提醒。
- **原生设置面板**：在 DSH 的「设置」左侧菜单里有专属的「通知与标题」页面，开关、提示音、阈值都能按需调整。

## 安装方法

### 方式一：在插件市场一键安装（推荐）

打开 DSH Desktop，进入 **设置 → 插件市场**，搜索 `dsh-completion-notifier` 或 `通知`，点击安装即可。

### 方式二：命令行安装

打开终端执行：

```bash
dsh plugin --profile web add dsh-completion-notifier
```

也可以直接通过 GitHub 地址安装：

```bash
dsh plugin --profile web add github:zepeng-jin/dsh-completion-notifier
```

### 方式三：本地开发

```bash
git clone https://github.com/zepeng-jin/dsh-completion-notifier.git
cd dsh-completion-notifier
dsh plugin --profile web add link:$(pwd)
```

## 设置选项

安装后在 DSH「设置」左侧边栏打开「通知与标题」，可以调整以下选项：

| 设置项 | 说明 | 默认值 |
| :--- | :--- | :--- |
| **启用完成通知** | 插件总开关，开启后对话完成时进行通知 | 开启 |
| **提醒时机** | 全量提醒（始终提醒）或 仅在未聚焦/后台时提醒 | 全量提醒 |
| **自动跳转到对应会话** | 后台任务完成或等审批时，自动将 DSH 视图切入该会话 | 关闭 |
| **DSH 应用内浮窗通知** | 在窗口右上角滑出轻量浮窗，解决前台时系统横幅被静默的问题 | 开启 |
| **macOS 系统通知横幅** | 是否在系统通知中心弹出横幅（点击可跳回会话） | 开启 |
| **完成提示音** | 任务跑完时播放的声音（内置 Glass、Ping、Hero、Pop 等） | Glass |
| **等待审批与 Plan 提交通知** | AI 暂停等待你授权、批准 Plan 或做选择时是否提醒 | 开启 |
| **最小提醒耗时阈值 (秒)** | 只有单轮耗时超过该秒数才提醒，设为 0 秒提醒所有对话 | 3 秒 |
| **首轮对话智能提炼标题** | 第一轮对话后自动将标题改为简明中文主题 | 开启 |
